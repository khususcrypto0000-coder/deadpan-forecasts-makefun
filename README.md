A single deadpan TV weather forecast for a city that does not exist: one line, delivered with total straight-faced confidence, about weather that is physically absurd yet reported like any other Tuesday. The forecast is written to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

## Why Vrellmark

Vrellmark is a city that exists only on the map in the presenter's head: the name was invented so no real town can complain about its weather, and so the forecast is free to be absurd while still sounding like something a calm TV meteorologist would say with a straight face.

The joke works because nothing in the delivery wavers: sideways rain at 70 km/h and a hailstorm that apologizes are reported with the same even tone as a sunny weekend, and that calm is what makes the absurd forecast feel almost believable.
